# Published evidence

This directory preserves the compact, Git-safe evidence from the completed
experiments. Large model, encoded-layer, calibration, and runtime-cache tensors
are excluded as described in [PUBLISHING_SCOPE.md](../PUBLISHING_SCOPE.md).

Raw records retain their original absolute execution paths. The audited
narrative ledger in [docs/sqg_mcg_experiment_record.md](../docs/sqg_mcg_experiment_record.md)
links to the corresponding files in this directory.
