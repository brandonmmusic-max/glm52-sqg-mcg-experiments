How a tiny trellis picks values, one step at a time

A hands-on view of QSRT’s two-bit compressor. For every number, it stores just two bits and uses its recent choices to decide which four replacement values are available.

What you are looking at

This is a small 16×16 patch of real Kimi-K3 expert weights: the gate matrix from layer 48, expert 17. A model uses many much larger matrices; this patch is just small enough to follow by eye.

Why use a trellis? A naive two-bit quantizer gives every number one of only four fixed replacement values. SQG still stores only two bits per number, but it lets a long run of numbers cooperate. The bits already written form shared decoder state. At each new number, that state fixes a phase—a precise position inside every broad quantile—and the two new bits choose one of the four quantiles. The decoder rebuilds the same state from the earlier bits, so no extra phase bits are needed. This turns four fixed levels into a much richer, sequence-dependent set of reconstruction points.

SQG: four choices, history-set precision

Two bits choose a band; earlier bits place one point within each band.

The phase is not an extra knob at the current number: it was determined by earlier choices. That is why the encoder searches a whole trellis trajectory. It can accept a small compromise now when that makes a better phase available for several later numbers.

To make the picture readable, the real decoded values are multiplied by 32 and five artificial +5 outliers are added. Every part of this demo uses those same teaching units. The Hadamard button mixes neighboring values without changing their total energy, showing why a large spike becomes easier to encode.

History as momentum

History is the recent stream of two-bit decisions, not earlier weight values. Each decision bends the route a little. The newest seven decisions are the 14-bit memory; SQG mixes that memory into the phase available at the next rung.

Same current two-bit choice, different history: the diagram compares two prior paths that take the same next code into the same quantile, but land at different positions inside that quantile.

A close-up of the decision

Read left to right: each vertical line is one matrix number. Up and down mean value, on a fixed scale from −2.5 to +2.5. The red dot and line show the number we would keep with unlimited precision. The orange dot is the value chosen for this step; the cyan curve connects the choices already made. The three dashed gray curves end at the other values that were legal at this step.

The four background bands are equal-sized groups in the compressor’s ordered value list. They look uneven because values near zero are packed more tightly than extreme values. Recent choices move the available point within each band, which lets the trellis plan for later numbers instead of making every choice independently.

Important: at this rung, the phase is already locked by the previous 14 bits. The encoder cannot directly choose it; all four branch choices use that same in-band phase. Its only immediate choice is the quantile. Viterbi earns its flexibility by choosing earlier branches with future phases in mind, steering today’s history so a useful phase is waiting when it reaches this number.

How a Hadamard mix disperses one spike

A normalized Hadamard transform repeatedly replaces a pair [a, b] with [(a + b)/√2, (a − b)/√2]. The highlighted row is processed in 2-, 4-, 8-, then 16-wide butterfly stages. This is a reversible rotation: it spreads an outlier’s contribution, but preserves the row’s total squared energy.

Hadamard is Fourier-like, but uses only + and −

Both transforms are orthonormal changes of basis: they preserve energy while expressing the same row in new coordinates. A Fourier transform uses smooth sine/cosine waves and complex phase. A Walsh-Hadamard transform uses these real +1 / −1 patterns instead, so its fast transform is only add/subtract butterflies.

A useful simile: striking one piano key creates a sharp event, but its sound contains many frequencies. Likewise, a single large weight coordinate has a contribution to many Walsh patterns; the transform exposes that distribution instead of leaving one coordinate to carry it all.

What happens at each step

1. Read
Take the highlighted number from the matrix.
2. Offer four choices
The recent bit history gives one possible replacement value in each of four broad regions.
3. Look ahead
The trellis compares the running error of possible routes. A choice also changes the choices available later.
4. Store two bits
Keep the best route’s two-bit code. The decoder can replay the same history and recover the chosen value.

This is a teaching version: it finds a good path through these 256 numbers using plain squared error. The production encoder adds a closed-loop boundary condition, calibrated scales, and feedback from earlier quantization errors. Those details change the final choices, not the basic idea shown here.
